## Enhancing Synthetic Biomedical Abstracts through Generation Strategies and Steering Vectors

#### Overview

This repository contains the implementation and experiments for my master’s thesis project on improving the quality and utility of synthetic biomedical abstracts generated by Large Language Models (LLMs).

The project investigates how different generation strategies, including zero-shot prompting, few-shot prompting, and steering vectors, affect the usefulness of synthetic biomedical text for downstream machine learning tasks.

The main objective is to generate synthetic biomedical abstracts containing predefined biomedical relations and evaluate how closely the generated data aligns with real biomedical literature.

#### Research Objectives

The project focuses on the following research questions:

- Can LLM-generated biomedical abstracts be effectively used as training data?
- How do different generation strategies affect synthetic data quality?
- Can steering vectors improve alignment between synthetic and real biomedical data distributions?
- How similar are synthetic and real abstracts in embedding and linguistic space?
